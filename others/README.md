# Others

用户主动分享、超出四个论文方向和 Official Lab Blogs 的论文、文章、项目与工具。用户已完成初筛；每条资源完成原文核验后直接收录，无法唯一核实原文的内容不列入本目录。

论文继续使用根目录的 `paper-template.md`；非论文使用 `resource-template.md`。保留原始资源链接、推送出处、收到日期和用户备注。自动发现流程不向本模块收集宽泛内容。
