## 五篇全文精读与收录建议

### 1. Video-DeepResearch（最推荐）

- **问题/连接**：现有多模态 Deep Research 多处理静态图片，视频任务会出现跨帧定位、视觉工具调用不足和参数记忆泄漏；它直接把 TVIR 的图文交错问题推进到连续视频。
- **训练/评测模型**：Qwen3-VL-30B-A3B-Instruct 和 Qwen3.5-35B-A3B 作为底座；SFT 后使用 GRPO。数据生成阶段使用 Qwen3.5-397B-A17B、Qwen3.5-35B-A3B；判分使用 Qwen3-VL-30B-A3B-Instruct。
- **Benchmark/数据**：30K video-grounded QA、7K 轨迹；VideoDR-Bench 200 个多跳 VQA（实验表使用 100 个人工标注 VQA 子集），并报告 Video-DR。
- **基线/指标**：Gemini 2.5 Pro、GPT-5、Claude-4.5-Sonnet、Qwen3.5-397B-A13B、Kimi K2.5、Qwen3-VL-30B-A3B-Instruct、Qwen3.5-35B-A3B；指标为准确率和视觉/文本工具调用。
- **核心结果**：Video-DeepResearch-35B-A3B 平均准确率 64.0%，超过 Claude-4.5-Sonnet 59.0%、GPT-5 52.5%、Gemini 2.5 Pro 57.5%；30B-A3B 为 59.3%，相对底座提升 18.8 个百分点。证据强度：**高**（arXiv HTML 给出完整表格和训练设置）。
- **机构/局限**：原文作者行仅显示 Video-DeepResearch Team，主要机构需进一步核对；视频 benchmark 的工具依赖过滤和 judge 模型仍可能影响泛化。

### 2. From Simple QA to Deep Research

- **问题/连接**：人工写高难 Deep Research 任务昂贵，自动生成又难以保证可验证性；论文将简单 NQ-Open 问题迭代成带 DAG checkpoints 和 pointwise rubrics 的任务。
- **训练/评测模型**：GPT-5.5 担任 Explorer、Formalizer、Challenger；用 Qwen3.7-Max 评估十个模型：DeepSeek-V4-Pro、Qwen3.7-Max、GLM-5.2、GPT-5.6 Terra、Claude Sonnet 5、Gemini 3.5 Flash、MiniMax-M2.5、Qwen3.6-Flash、Qwen3-32B、Qwen3-14B。
- **Benchmark/数据**：500 个任务，31 个主题、10 类领域；三种 query 形式，平均 104.85 checkpoints，任务知识 checkpoints 共 10,695 条并人工检查。
- **基线/指标**：十模型在 agent mode 与 model mode 对比；指标为 evidential/analytical checkpoints 的加权得分（E+A）。
- **核心结果**：GPT-5.6 Terra 在 agent mode 的 hidden-goal、open-ended、assigned-topic 三类总体得分分别为 0.86、0.67、0.70；去掉工具后十模型平均下降 0.14。任务演化成功率 96.3%，182 小时人工审查 100 任务，Fleiss κ=0.81。证据强度：**高**。
- **机构/局限**：原文仅明确列出 Shandong Key Laboratory，其他作者机构上标需核对；任务由 GPT-5.5 生成，可能带来生成器偏差。

### 3. Scaling Harness Intelligence via Just-in-Time Harness Evolution（JIT-Agent）

- **问题/连接**：模型权重之外，memory、planning、action protocol 和工具编排的 harness 常决定长链任务效果；论文把 harness 设计变成可训练、可迁移、可递归积累的对象。
- **训练/评测模型**：JIT-Agent 基于 Qwen3.6-27B 训练；主要挂载 GLM-5.2 和 DeepSeek-V4-Flash-Preview，并用 Qwen3.6、Mimo-V2.5 测试迁移。
- **Benchmark/数据**：九个 benchmark：BrowseComp-Plus、DeepSearchQA、xBench-DeepSearch、AgentIF-Oneday、PinchBench、DeepPlanning-Shopping、DeepPlanning-Travel、OfficeBench、OdysseyBench。
- **基线/指标**：vanilla Qwen3.7-Plus、GLM-5.2、DeepSeek-V4-Flash/Pro、Kimi K2.7 Code、GPT-5.6、Gemini 3.1 Pro/3.5 Flash；固定 backbone 时再与 Claude Code、Codex、OpenCode、Hermes、NanoBot 比较。指标统一 0–100，含 accuracy、answer F1、rubric score、成功率、成本/延迟。
- **核心结果**：18 个 backbone–benchmark 配对全部提升；GLM-5.2 九项平均 74.1→81.8（+7.7），DeepSeek-V4-Flash 66.7→75.5（+8.8）；JIT+GLM-5.2 在 DeepSearchQA 93.9、AgentIF 69.9、PinchBench 93.3，JIT+DeepSeek 在 DeepPlanning-Shopping 83.9。证据强度：**高**。
- **机构/局限**：论文页显示 LV-NUS Lab，完整机构需核对；harness 生成器和底座模型均较新，独立复现成本较高。

### 4. Agent Lightning v1.0: Towards Harnessed Agentic RL

- **问题/连接**：传统 RL 框架由训练器掌控环境循环，而实际 agent harness 掌控工具和上下文，导致 retokenization、sample merging、advantage 和 loss normalization 不一致；论文提供约 3,500 行的可复现实验框架。
- **训练/评测模型**：搜索 agent 使用 Llama-3.2-3B-Instruct + GRPO；通用 instruction-following 使用 Qwen3-4B-Instruct-2507 + RLOO；coding agent 使用 Qwen3.5-9B + mini-SWE-agent harness。
- **Benchmark/数据**：搜索训练为 HotpotQA，评测另含 2WikiMultiHopQA、MuSiQue、Bamboogle、TriviaQA、Natural Questions；通用任务使用 Instruction Pre-Training 数据；coding 使用 SWE-smith（最终约 6K train/400 test）和 SWE-bench Verified。
- **基线/指标**：不同 advantage/loss normalization 变体及传统训练设置；搜索用 exact match，通用任务用 validation reward，coding 用 SWE-bench Verified pass rate。
- **核心结果**：搜索 validation reward 25.1%→41.7%（+16.6）；通用 instruction-following 51.9%→70.2%（+18.3）；Qwen3.5-9B 在 SWE-bench Verified 41.8%→56.4%（+14.6），仅使用约 6K 训练样本。证据强度：**高**。
- **主要机构**：Microsoft、Fudan University、Zhejiang University、University of Edinburgh；代码和训练脚本公开。

### 5. Search, Inspect, Fetch（SIEVE）

- **问题/连接**：Search–Visit 把整页网页塞入上下文，浪费 token 且干扰证据选择；SIEVE 用字段级 Boolean Query Language、结构化结果卡和按 section fetch，把证据链粒度降到“需要的段落”。
- **训练/评测模型**：三种 agent backbone：Tongyi-DeepResearch、Qwen-AgentWorld、OpenResearcher；检索器覆盖 BM25、dense、BM25+dense 等组合。
- **Benchmark/数据**：配对的结构化/扁平化 HotpotQA、MuSiQue、BrowseComp-Plus；每次搜索最多 5 个结果、最多 100 agent steps，网页访问上限 12,000 tokens。
- **基线/指标**：Search–Visit、Search–AutoRead、直接语料访问（DCI）等；指标为回答准确率和 distinct-token 使用量，并分析 ranker/backbone 鲁棒性。
- **核心结果**：三个 QA collection 上均超过最强 Search–Visit 配置，同时减少 20.7%–50.6% token；BQL 过滤对不同 ranker 和三种 agent backbone 的收益保持。证据强度：**高**。
- **主要机构/局限**：University of Queensland、CSIRO；论文报告了空回答 recovery overlay 和结构化/非结构化条件的不对称，跨条件比较需谨慎。
