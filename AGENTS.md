# Repository Instructions

This repository curates high-relevance, deep-read papers about multimodal Deep Research.

Before every review run, read `README.md`, `CONTEXT.md`, `PROCESS.md`, `seed_papers.md`, and `AUTOMATION.md`.

Use one primary Track per paper: `Data Synthesis`, `Rubric RL`, or `Harness RSI`. A paper may have auxiliary tags but must appear only once in the README. Preserve original English titles, write notes in Chinese, and record submitted date, last update, version, authors, and major institutions from the primary paper/project source.

Do not save PDFs or architecture diagrams/links. Each paper page must include an experimental results summary covering models, benchmarks/data, baselines, metrics, and key results. Do not invent affiliations, metrics, citation relationships, or experiment details; write “待核对” when the source is insufficient. Run `python3 scripts/check_repo.py` before creating a Draft PR. Never merge the PR automatically.
